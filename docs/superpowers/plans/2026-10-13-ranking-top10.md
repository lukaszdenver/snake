# Ranking top 10 — plan implementacji

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wspólny ranking 10 najlepszych wyników gry Snake, przechowywany w Supabase, z listą pod planszą i formularzem imienia po przegranej.

**Architecture:** Tabela `public.wyniki` w Supabase z ograniczeniami `check` i RLS (czytanie + dodawanie dla `anon`). Nowy plik `ranking.js` (bez DOM) rozmawia z REST API Supabase przez `fetch` i udostępnia czyste funkcje `normalizeName` / `qualifies`. `index.html` rysuje listę i formularz w HTML pod Canvasem i wykrywa koniec gry w pętli `requestAnimationFrame`.

**Tech Stack:** HTML5, Canvas 2D, JavaScript ES5/ES2015 bez modułów, `fetch` + `AbortController`, Supabase (PostgreSQL + PostgREST), testy w `tests.html` uruchamiane w Edge headless.

**Spec:** `wymagania-snake.md` — sekcja 9 (ranking), sekcja 10 (kryteria akceptacji 22–28 i 10.2 pkt 12–19), sekcja 11 (decyzje odrzucone).

## Global Constraints

- Zero modułów ES (`type="module"`, `import`, `export`) — gra musi działać po dwukliku z `file://`.
- Zero bibliotek z sieci; do Supabase tylko `fetch`.
- Adres REST tabeli: `https://bakmagtitoppdzuolyvg.supabase.co/rest/v1/wyniki`.
- Klucz: `sb_publishable_gTyd8RfeoCgdeFwVjXxVRA_9BV-POkI` (publishable, publiczny). Klucz secret nigdy nie trafia do repozytorium ani do kodu.
- Imię: 1–20 znaków liczonych jako punkty kodowe, bez samych białych znaków. Punkty: 1–397.
- Kolejność rankingu: `punkty` malejąco, przy remisie `utworzono` rosnąco.
- Limit czasu każdego zapytania: 8 s.
- Imiona z bazy wstawiane wyłącznie przez `textContent`, nigdy `innerHTML`.
- Klucz `localStorage`: `snake.imie`; każdy dostęp w `try/catch`.
- Teksty interfejsu dosłownie: „Top 10”, „Ładowanie…”, „Brak wyników — bądź pierwszy!”, „Ranking niedostępny”, „Twoje imię”, „Zapisz”, „Nie udało się zapisać — spróbuj ponownie”, „Nowy wynik w top 10 — wpisz imię pod planszą”.
- Logika gry (`snake-logic.js`) się nie zmienia; testy 1–21 muszą dalej przechodzić.

```sql
-- Ranking top 10 gry Snake. Uruchamiać w Supabase: SQL Editor -> New query -> Run.
-- Skrypt można uruchomić ponownie: nie usuwa danych, odtwarza uprawnienia i polityki.

create table if not exists public.wyniki (
  id bigint generated always as identity primary key,
  imie text not null
    check (char_length(imie) between 1 and 20 and imie ~ '[^[:space:]]'),
  punkty int not null
    check (punkty between 1 and 397),
  utworzono timestamptz not null default now()
);

create index if not exists wyniki_ranking_idx
  on public.wyniki (punkty desc, utworzono asc);

alter table public.wyniki enable row level security;

-- Najpierw odbieramy wszystko, potem nadajemy tylko to, czego potrzebuje gra.
revoke all on public.wyniki from anon, authenticated;
grant select on public.wyniki to anon;
-- Gracz ustawia tylko imię i punkty; id i utworzono nadaje baza.
grant insert (imie, punkty) on public.wyniki to anon;

drop policy if exists wyniki_select_anon on public.wyniki;
create policy wyniki_select_anon on public.wyniki
  for select to anon using (true);

drop policy if exists wyniki_insert_anon on public.wyniki;
create policy wyniki_insert_anon on public.wyniki
  for insert to anon with check (true);

-- Brak uprawnień i polityk na update/delete: wpisów nie da się zmienić ani usunąć kluczem publishable.
```

```js
// Ranking top 10 w Supabase. Bez DOM i Canvas; jedyny kontakt z otoczeniem to fetch i eksport window.SnakeRanking.
(function (global) {
  'use strict';

  var TOP_N = 10;
  var MAX_NAME = 20;

  // Długość liczona w punktach kodowych, tak jak char_length w Postgresie (emoji = 1 znak).
  function normalizeName(raw) {
    var trimmed = String(raw == null ? '' : raw).trim();
    var name = Array.from(trimmed).slice(0, MAX_NAME).join('').trim();
    return name ? name : null;
  }

  // Remis z 10. miejscem nie wystarcza: przy równych punktach wyżej jest starszy wpis.
  function qualifies(top, score) {
    if (score < 1) return false;
    return top.length < TOP_N || score > top[TOP_N - 1].punkty;
  }

  global.SnakeRanking = {
    normalizeName: normalizeName,
    qualifies: qualifies
  };
})(window);
```

```js
  // fetch z kluczem i limitem czasu; status spoza 2xx to błąd.
  function request(url, options) {
    var ctrl = new AbortController();
    var timer = setTimeout(function () { ctrl.abort(); }, TIMEOUT_MS);
    options.signal = ctrl.signal;
    options.headers = Object.assign({ apikey: API_KEY }, options.headers);
    return fetch(url, options).then(function (res) {
      clearTimeout(timer);
      if (!res.ok) throw new Error('HTTP ' + res.status);
      return res;
    }, function (err) {
      clearTimeout(timer);
      throw err;
    });
  }

  function fetchTop() {
    var url = ENDPOINT + '?select=imie,punkty&order=punkty.desc,utworzono.asc&limit=' + TOP_N;
    return request(url, { method: 'GET' }).then(function (res) { return res.json(); });
  }

  function submit(name, score) {
    var imie = normalizeName(name);
    if (imie === null) return Promise.reject(new Error('Puste imię'));
    return request(ENDPOINT, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json', Prefer: 'return=minimal' },
      body: JSON.stringify({ imie: imie, punkty: score })
    }).then(function () {});
  }
```

```js
        try { localStorage.setItem(NAME_KEY, name); } catch (e) { /* brak dostępu nie psuje gry */ }
      }

      function renderTop() {
        topListEl.textContent = '';
        if (topList === null || topList.length === 0) {
          topStatusEl.textContent = topList === null ? 'Ranking niedostępny' : 'Brak wyników — bądź pierwszy!';
          topStatusEl.hidden = false;
          return;
        }
        topStatusEl.hidden = true;
        topList.forEach(function (w) {
          var li = document.createElement('li');
          li.textContent = w.imie + ' — ' + w.punkty;
          topListEl.appendChild(li);
        });
      }

      function refreshTop() {
        return R.fetchTop().then(
          function (rows) { topList = rows; },
          function () { topList = null; }
        ).then(renderTop);
      }

      function hideForm() {
        newRecord = false;
        formEl.hidden = true;
        msgEl.hidden = true;
        if (formEl.contains(document.activeElement)) document.activeElement.blur();
      }

      // Wywoływane raz, w klatce, w której gra przeszła z 'running' na 'over' albo 'won'.
      function onGameEnd() {
        newRecord = topList !== null && R.qualifies(topList, state.score);
        if (!newRecord) return;
        inputEl.value = loadName();
        msgEl.hidden = true;
        btnEl.disabled = submitting;
        formEl.hidden = false;
        inputEl.focus();
        inputEl.select();
      }

      function newGame() {
        state = L.createState();
        accumulator = 0;
        gameId++;
        hideForm();
      }

      formEl.addEventListener('submit', function (e) {
        e.preventDefault();
        if (submitting) return;
        var name = R.normalizeName(inputEl.value);
        if (name === null) {
          inputEl.focus();
          return;
        }
        var forGame = gameId;
        submitting = true;
        btnEl.disabled = true;
        msgEl.hidden = true;
        R.submit(name, state.score).then(function () {
          saveName(name);
          if (forGame === gameId) hideForm();
          return refreshTop();
        }, function () {
          // Po restarcie komunikat o starej grze byłby mylący.
          if (forGame === gameId) msgEl.hidden = false;
        }).then(function () {
          submitting = false;
          btnEl.disabled = false;
        });
      });

      formEl.addEventListener('keydown', function (e) {
        if (e.key === 'Escape') hideForm();
      });
```
